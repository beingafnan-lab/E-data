# 📊 Superstore Sales Data Analysis using Python

## 📌 Project Overview

This project performs an exploratory data analysis (EDA) on the Superstore Sales dataset using Python. The objective is to uncover business insights related to sales, profit, customer segments, and product categories through data cleaning, analysis, and interactive visualizations.

---

## 🎯 Objectives

- Analyze monthly sales trends.
- Compare sales across product categories and sub-categories.
- Evaluate profit distribution.
- Measure sales-to-profit ratio.
- Analyze customer segments based on sales and profit.
- Create interactive visualizations using Plotly.

---

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly Express
- Plotly Graph Objects

---

## 📂 Dataset

The project uses the **Sample Superstore** dataset containing:

- Order Details
- Customer Information
- Product Information
- Sales
- Quantity
- Discount
- Profit
- Region

---

## 📊 Data Preprocessing

The following preprocessing steps were performed:

- Loaded the dataset using Pandas
- Checked data types and missing values
- Converted **Order Date** to datetime format
- Created new features:
  - Order Month
  - Order Year
  - Order Day of Week

---

## 📈 Analysis Performed

### 1. Monthly Sales Analysis
- Calculated monthly sales.
- Created an interactive line chart.

### 2. Sales by Category
- Compared sales across:
  - Furniture
  - Office Supplies
  - Technology
- Visualized using a donut chart.

### 3. Sales by Sub-Category
- Identified top-performing product sub-categories.
- Displayed using a bar chart.

### 4. Profit by Category
- Compared profit generated by each category.
- Visualized using a pie chart.

### 5. Profit by Sub-Category
- Analyzed profitable and loss-making sub-categories.
- Displayed using a bar chart.

### 6. Sales to Profit Ratio
- Calculated the overall sales-to-profit ratio.

### 7. Customer Segment Analysis
Compared:
- Consumer
- Corporate
- Home Office

Visualized sales and profit using grouped bar charts.

---

## 📌 Key Insights

- Technology generated the highest overall sales.
- Office Supplies contributed significantly to profit.
- Tables and Bookcases resulted in negative profits.
- Consumer customers generated the highest sales.
- Sales peaked during November and December, indicating seasonal demand.
